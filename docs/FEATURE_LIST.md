# iDuoPreviewer 功能点清单

> 详细设计说明见 `PRD.md`，此文件仅用于打钩追踪开发进度。

## V1.0 MVP（必须做）—— 已全部完成 ✅

### 布局
- [x] 上下结构：预览区 + 上传/网址输入区

### 预览区
- [x] 设备外框（内屏对称圆角 / 外屏 D 形非对称圆角）
- [x] 图片渲染（object-fit: contain/cover 切换）
- [x] PDF 渲染 + 翻页（pdf.js，默认显示第1页）
- [x] 网页 iframe 嵌入预览（超时未加载成功给文案提示 + "在新标签页打开"兜底，不做截图兜底）
- [x] 填充模式切换：Contain / Cover
- [x] 内外屏切换按钮（分段控制器 + 切换动画）
- [x] 安全区辅助层浮层（半透明色块，标出刘海/灵动岛、铰链/手势条区域，内外屏联动，默认关闭手动开启）
- [x] 横屏/竖屏切换按钮（内外屏各自独立支持，MVP 先做单一固定旋转方向，不做双向镜像）

### 上传/输入区
- [x] 拖拽上传 + 点击选择文件（图片/PDF，本地渲染不上传服务器）
- [x] 文件校验（格式、大小）+ 错误提示（Toast 文案提示）
- [x] "已选中文件"状态展示（文件名/大小/更换按钮）
- [x] 网址输入框 + 预览按钮（协议头自动补全、格式校验）
- [x] 加载态 / 超时兜底（iframe 6 秒超时未加载则提示"在新标签页打开"，不做自动重试）

### 基础状态
- [x] 空状态引导文案
- [x] 异常状态提示（格式不支持/超大/网址不可达/PDF损坏）

## 已完成（超出原始 MVP 范围的功能）

- [x] **多语言 / 国际化（中/英文切换）**：基于 `vue-i18n`，右上角提供 EN / 中文切换按钮，选择结果记忆在浏览器本地存储中，下次打开自动沿用；默认语言为英文，未匹配到语言包时回退英文。详见 `PRD.md` 新增章节与 `TECH_SPEC.md` 技术方案。
- [x] 图片预览支持鼠标滚轮缩放 + 拖拽平移（`@panzoom/panzoom`），用于查看像素级细节，比 PRD 里设想的"原始尺寸 1:1 可滚动查看"体验更完整。
- [x] 全局 Toast 提示组件，用于文件超限、格式不支持、网址非法等错误提示的统一呈现。
- [x] 页脚 Contact 区块（预览工具之外的获客入口，非核心预览功能）。
